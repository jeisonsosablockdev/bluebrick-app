# Knowledge Base (OKF)

This folder contains the Open Knowledge Format documentation for the project.

- `governance/`: Non-negotiable policies and quality standards.
- `architecture/`: Architectural Decision Records (ADRs), state machines, and threat models.
- `features/`: Feature problem & solution dual artifacts.
- `fixes/`: Fix problem & solution dual artifacts.
- `templates/`: Canonical templates for RFCs, features, and fixes.
